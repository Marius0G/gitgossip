Privacy Policy

Effective 5 October 2026

Git Gossip is a personal project that publishes short tech-news videos on Instagram, YouTube and TikTok. Its videos are uploaded by a private publishing tool (registered with Google, Meta and TikTok as "Reels Publisher", "GitGossip Publisher" and "GitGossip Uploader"). This policy explains what that tool accesses and what it does with it.

Who uses the tool

Only the owner of Git Gossip. The tool is not offered to the public, and nobody else can sign in to it. It only connects to Git Gossip's own accounts.

What it accesses

  • YouTube (through the YouTube API Services): uploading videos to the Git Gossip channel and reading those videos' details and statistics, such as views, likes, comments and watch time.
  • Instagram (through the Instagram API with Facebook Login): publishing reels to the Git Gossip account and reading their insights. If enabled, it also reads comments on Git Gossip's own posts to send a requested link to the commenter by private reply.
  • TikTok (through Login Kit, the Content Posting API and the Display API): sending videos to the Git Gossip account's drafts and reading basic profile information and video statistics.

The tool does not access anyone else's accounts. It doesn't collect personal information about viewers, beyond reading comments left on Git Gossip's own posts when replying to them.

How the data is used and stored

Video statistics are used only to understand which videos perform best and to improve future videos. Access tokens and statistics are stored locally on the owner's computer. The data is not sold, not shared with third parties, not used for advertising, and not used to train AI models.

Google and YouTube

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

  • Google / YouTube: myaccount.google.com/permissions
  • Instagram / Facebook: Facebook Settings → Business integrations
  • TikTok: Settings and privacy → Security → Manage app permissions

Stored statistics are deleted within 30 days when access is revoked or on request.

Changes and contact

If this policy changes, the new version will be posted on this page with a new effective date. Questions: gitgossip@gmail.com
